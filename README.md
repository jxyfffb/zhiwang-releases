## 本次功能

支持 WorkBuddy、WorkBuddyAI、Codex、千问办公及豆包工作本地文字记录的授权收录、统一检索和原文核对。
可按图片、表格、文档、视频、网页查找产出，并与平台、日期、关键词组合筛选。
豆包仅覆盖本机保留的工作模式原文，未缓存的云端历史暂无法补全。

## 升级

先退出织网后台和正在调用织网的 AI，再将新版覆盖安装到原位置，无需先卸载。
同机同用户保留原记录、来源授权、客户端配置和仍有效的激活状态。新增来源需单独授权。
安装包 SHA256 见对应发布中的 SHA256SUMS.txt。软件暂未提供在线一键更新。

## 0.6.1 更新

- 修复千问已交付的 Excel、文档、图片等文件卡片未进入产出筛选的问题，可按文件名搜索并回到原聊天。
- MCP 返回原聊天及已关联文件的本地路径、类型和存在状态，附件正文由目标客户端按自己的本地能力读取。
- 缺少来源目录时提示对应客户端，保留原索引；覆盖升级保留原记录、来源授权、MCP 配置和仍有效的激活。

## 0.6.0 更新

- 修复豆包部分历史会话导致整批收录失败，异常记录会保留索引并单独重试。
- 支持选择或拖入 Markdown，也可粘贴其他 AI 的讨论；预览确认、保留来源和原文、重复检查。
- 保存后按事情或关键词查找，已连接织网的 AI 可通过 MCP 读取并接着做。
- 手动导入中的图片和附件只保留原文链接，不自动下载或读取。

0.4.0、0.5.0 和 0.6.0 安装包继续保留作历史归档。0.6.1 由作者先行测试确认，再向学员分发。
